1. Create Backend
- Specify where to place the state 
- I did the remote state so, we specify using

terraform {
  backend "s3" {
    bucket       = "motorsport-terraform-state"
    key          = "main/terraform.tfstate"
    region       = "us-east-1"
    use_lockfile = true
  }
}
- bucket = location
- key = where to store within bucket
- region = bucket location
- use_lockfile = enables native state locking
  Prevents two people from updating the state file at the same time
